# Demo task

Translate the synthetic English paper in the same directory into Chinese as an
auditable bilingual result:

- build a glossary and use one translation per term throughout;
- keep one translated segment per source paragraph, with stable paragraph ids;
- preserve numbers, units, formulas, figure numbers and citation markers exactly;
- keep negation and limiting conditions (for example "was not reported");
- give the basis for each non-trivial translation choice;
- list anything that needs human confirmation.

Anything not stated in the source must be reported as an uncertainty, not
translated into a new claim. This is a synthetic example, not official case output.
